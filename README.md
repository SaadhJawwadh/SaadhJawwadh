## 🎓 Bridging Academia & Industry

> *"I believe curiosity is one of the important characteristics that induce me to learn new things and I am always willing to learn new things."*

As an academic and researcher, my primary driver is taking complex theoretical concepts out of the lecture hall and deploying them into practical, high-performance software ecosystems. 

* 🏛️ **In the Lab:** Researching Explainable AI (XAI) and Reinforcement Learning architectures to autonomously mitigate network-level DDoS threats and identify software vulnerabilities.
* 🏭 **In Production:** Architecting secure, production-grade applications that prioritize data autonomy and low-latency operation.

---

## 🔬 Key Engineering & Research Focus Areas

### 🛡️ Deep Security & Explainable AI
* **Threat Mitigation:** Training intelligent agents capable of parsing live network traffic anomalies.
* **XAI Architectures:** Implementing transparent machine learning models to build human-interpretable defense mechanisms.
* **Vulnerability Analysis:** Exploring automated deep learning pipelines to catch memory and logic flaws before deployment.

### 📱 Local-First Software Ecosystems
* **Data Autonomy:** Architecting decentralized application architectures that operate entirely without a cloud bottleneck.
* **Embedded Security:** Integrating cross-platform runtime environments (Flutter/Dart) with securely encrypted local storage systems (`SQLite` + `SQLCipher`).
* **Automation Engines:** Writing local tools for batch processing and workflow optimization (such as bulk pdf-watermarking).
